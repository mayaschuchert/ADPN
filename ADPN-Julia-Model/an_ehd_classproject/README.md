# ADPN EHD — Class Project Snapshot

Self-contained snapshot of the ADPN electrohydrodimerization model and its
published kinetics fit, packaged for a class project. The fit is **frozen**
here — the parent project (`../an_ehd_v2/`) is where development continues.

## What the model does

A 1-D continuum model of acrylonitrile (AN) electrohydrodimerization in the
Bloomquist 2024 reactor. Kinetics fitted to 162 experimental rows (gap × flow
× current density × organic loading); model predicts faradaic efficiency
toward four cathodic products: ADN, PN, HER (H₂), and TCH.

**Steady-state physics per cell:** 9 log-concentrations (H⁺, OH⁻, three
phosphate species, AN, ADN, PN, TCH) + 1 ionic potential φ_l. N=100 cells
discretized with geometric grading. Block-tridiagonal Jacobian (half-bandwidth
19), banded FD or galvanostatic-augmented Newton.

## Published fit

Eight kinetic parameters at the cathode (ADN/PN/TCH each have j₀, αc, n; HER
has j₀ and αc only — frozen at v6.x converged values, n is implicit in the
single-reactant Tafel). Source: `output/data/fitted_theta.txt`.

```
j0_ADN  = 2.703e-3 A/m²    αc_ADN = 0.567    n_ADN = 0.629
j0_PN   = 1.152e-3 A/m²    αc_PN  = 0.507    n_PN  = 0.966
j0_HER  = 2.666e-5 A/m²    αc_HER = 0.390    (frozen)
j0_TCH  = 1.701e-3 A/m²    αc_TCH = 0.519    n_TCH = 1.826
```

These came from a sequential-decoupled fit (Bloomquist SI §S1.11) on
**pre-kink-fix physics** (when Na⁺ was missing from the φ_l current
conservation), recovered from the run log. The plot data in
`output/data/parity.csv` was generated by **forward-applying** these
parameters to the **post-kink-fix** physics (Na⁺ now in φ_l), which is
the corrected model.

## How to run

### 1. Regenerate the published outputs from `fitted_theta.txt`
```bash
julia --project=. publish_fit.jl
```
Wall: ~5–8 min on a laptop. Writes `output/data/{parity.csv, *_residuals.csv,
fitted_theta.txt, summary.txt}` from scratch. Validates the model code
end-to-end.

### 2. Make plots
```bash
python plot_parity.py        # → output/plots/parity_combined.png
python plot_residuals.py     # → output/plots/resid_FE_*.png  (6 plots)
python plot_weber_maps.py    # → output/plots/weber_maps.png  (model FE_ADN cube)
```

### 3. Optional — regenerate the species-profile plot
```bash
julia --project=. gen_profile_for_plot.jl    # writes output/data/profile_operating.csv
python plot_species_profiles.py              # → output/plots/species_profiles.png
```

### Python dependencies for plots

`numpy`, `pandas`, `matplotlib` for all scripts; `scikit-learn` additionally
for `plot_weber_maps.py` (uses Gaussian-process regression to interpolate the
model's FE_ADN over the flow-regime cube).

## Decision gates (Core RMSE thresholds)

```
[FAIL] Core FE_ADN RMSE   8.16 pp   (< 8 pp threshold; misses by 0.16)
[PASS] Core FE_PN  RMSE   4.94 pp   (< 5 pp)
[FAIL] Core FE_TCH RMSE   6.24 pp   (< 4 pp threshold; the n_TCH=1.83 fits Core
                                      but TCH overshoots low-φ rows under post-fix physics)
[PASS] Extended  FE_ADN   9.58 pp   (< 12 pp)
[FAIL] Holdout   FE_ADN  30.48 pp   (gap=0.25 mm rows generalize poorly — expected)
```

The remaining discrepancies are physics-limited, not fitting-limited:
4 rows at φ_AN=0.04, j=131 mA/cm² require AN consumption rates that exceed
the single-phase Lévêque transport limit. A salting-out correction to
EPS_ORG_SAT (deferred) would resolve them.
